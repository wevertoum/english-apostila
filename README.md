# Apostila de inglês — afirmar, negar, perguntar

Material para falantes de português brasileiro.

Ideia central:

> **AFIRMAR → NEGAR → PERGUNTAR**  
> **PRESENT → PAST → FUTURE**

O objetivo não é decorar listas de regras. É entender a **lógica de construção das frases**, principalmente o papel dos auxiliares, até produzir frases novas sem traduzir palavra por palavra.

Cada capítulo fica em um arquivo Markdown próprio, na pasta [`apostila/`](apostila/).

---

## Como estudar

1. Leia a explicação em voz alta nos exemplos.
2. Faça os exercícios por escrito.
3. Repita os drills de fala sem olhar.
4. Só então confira o gabarito.

Prioridade: **lógica → padrão → exemplos → repetição → automatização → fala.**

## As quatro estruturas da apostila

1. **Verbos comuns** — do / does / did / will  
2. **To be** — am / is / are / was / were / will be  
3. **Modais** — can, could, should, would, may, might, must  
4. **Have** — verbo principal e auxiliar dos perfect tenses  

---

## Mapa 3 × 3 ( Cap. 1 )

Verbo-modelo: **need**

|  | Present | Past | Future |
|---|---|---|---|
| Afirmar | I need. | I needed. | I will need. |
| Negar | I don't need. | I didn't need. | I won't need. |
| Perguntar | Do you need? | Did you need? | Will you need? |

Regra de ouro: quando um auxiliar indica tempo, negação ou pergunta, o verbo principal normalmente fica na **forma base**.
