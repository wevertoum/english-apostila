# Capítulo 9 — Os 60 verbos mais importantes

> Objetivo deste capítulo: repetir o **mesmo molde** em 60 verbos de alta frequência, até o cérebro parar de tratar cada verbo como um caso novo.

Não transforme cada item numa aula. Leia em voz alta: afirmativa → negativa → pergunta → passado → futuro. Depois as frases de uso.

---

## 9.1 Como usar esta lista

Para cada verbo, o molde é o do Capítulo 1:

```
I + VERBO
I don't + BASE
Do you + BASE?
I + PASSADO
I didn't + BASE
I'll + BASE
```

Exceções que você já conhece:

- **be** — am/is/are · was/were · will be *(sem do)*  
- **modais** não estão nesta lista; eles **acompanham** estes verbos: *I can go, I should send*  
- **have** aparece como “ter” e, no particípio, como peça de perfect  
- **do** aparece como “fazer” e como auxiliar  

**Pronúncia** aqui é aproximação para ouvido brasileiro, não IPA. O passado/particípio irregular vale mais do que a transcrição perfeita.

Marque com um ponto os 15 que você mais fala no trabalho. Treine esses primeiro. Os outros ficam para reconhecimento.

## 9.2 Os 60 verbos

### 1. be — ser / estar
**Fala:** *bi* · **Passado:** was / were · **Particípio:** been  
- I am ready. / I'm not ready. / Are you ready?  
- I was late. · I'll be there.  
- **Uso:** I'm not sure. / Are you free now? / I'll be there in five minutes.

### 2. have — ter
**Fala:** *hév* · **Passado:** had · **Particípio:** had  
- I have time. / I don't have time. / Do you have time?  
- I had a meeting. · I'll have the file later.  
- **Uso:** Do you have five minutes? / I don't have the latest version. / She has a call at three.

### 3. do — fazer
**Fala:** *du* · **Passado:** did · **Particípio:** done  
- I do this every day. / I don't do that. / Do you do this every week?  
- I did my part. · I'll do it now.  
- **Uso:** Can you do me a favor? / I didn't do that. / I've already done it.

### 4. say — dizer
**Fala:** *sêi* · **Passado:** said (*séd*) · **Particípio:** said  
- I say this a lot. / I don't say that. / Do you say that at work?  
- I said I was sorry. · I'll say something in the meeting.  
- **Uso:** What did he say? / I didn't say that. / I don't know what to say.

### 5. go — ir
**Fala:** *gôu* · **Passado:** went · **Particípio:** gone

- I went home. · I'll go after lunch.

### 6. get — pegar / conseguir / receber / ficar

## 9.4 Drill rápido (10 verbos)

Para cada um, fale as nove formas do mapa (I + you nas perguntas):

need · want · like · know · think · work · call · help · use · make

Depois 5 irregulares, só passado:

go · see · send *(sent/sent)* · take · write

2. think  
3. make  
4. leave  
5. write

### Exercício 2 — Depois de DID, a base

1. Did you _____ (went / go)?  
2. I didn't _____ (saw / see) it.  
3. Did she _____ (told / tell) you?  
4. We didn't _____ (took / take) long.  
5. Did they _____ (wrote / write) the spec?

### Exercício 3 — Particípio (I've / she's)

1. I've _____ (see) that.  
2. She's _____ (go) home.  
3. We've _____ (do) our part.  
4. Have you _____ (write) it?  
5. I've _____ (know) her for years.

### Exercício 4 — Qual verbo?

1. _____ me know.  
2. I don't _____ so.  
3. Can you _____ me the link? *(send não está nos 60; use um da lista que sirva, ou **give**)*  
4. That doesn't _____ sense.  
5. I'll _____ you later. *(ligar)*  
6. What do you _____? *(querer dizer)*  
7. I _____ a bug.  
8. _____ you have five minutes?

### Exercício 5 — Três intenções no presente (she)

Escreva afirmar / negar / perguntar com: **need, work, have, like, go**.

4. Me avisa.  
5. Isso não funciona.  
6. Eu perdi o acesso.

## Resumo do capítulo

1. Sessenta verbos, **um molde**.  
2. Irregular: afirme com a forma especial; depois de **did/will/can**, use a **base**; no perfect, o **particípio**.  
3. **be / have / do** continuam famílias especiais.  
4. Frases curtas de conversa valem mais do que listas soltas.  
5. Priorize os 15 do seu dia. O resto é reconhecimento.
