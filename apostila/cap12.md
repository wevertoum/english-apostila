# Capítulo 12 — Inglês → português

> Objetivo deste capítulo: provar que você **reconhece a estrutura**, não só que decorou frases soltas.

Para cada frase, faça duas coisas, nesta ordem:

1. **Etiqueta:** intenção (afirmar / negar / perguntar) + tempo ou família (presente, passado, futuro, BE, modal, have-perfect).  
2. **Tradução** natural em português.

Se a etiqueta sair errada, a tradução vai sair errada mesmo com vocabulário conhecido. *Did* não é “fazer”. *Do* na frente não é “fazer”. *Will* não é “vontade”.

Não olhe o gabarito.

---

## 12.1 O que cada peça grita

| Se você vê | A frase está dizendo |
|---|---|
| **do / don't** + base | presente, I/you/we/they, pergunta ou negação |
| **does / doesn't** + base | presente, he/she/it |
| verbo com **-s** (works, needs) | presente afirmativo, he/she/it |
| **did / didn't** + base | passado, pergunta ou negação |
| verbo no passado (worked, went) sem did | passado afirmativo |
| **will / 'll** + base | futuro afirmativo |
| **won't** + base | futuro negativo |
| **can / can't** | modal, capacidade ou pedido |
| **should / shouldn't** | modal, conselho |
| **am / is / are** | BE presente |
| **was / were** | BE passado |
| **have/has** + particípio | perfect, ligação com agora |
| **have/has** + substantivo | verbo “ter” |

## 12.2 Por que a etiqueta vem antes da tradução

**I didn't understand what he said.**

Se você ler *didn't* como “não fiz”, a frase vira lixo.  
*Didn't* = passado + negação. *Understand* = entender. *Said* = disse.

→ Eu não entendi o que ele disse.

**She's worked here for years.**

*She's* aqui não é “ela está”. O próximo som é particípio (**worked**). Então *she has*.

→ Ela trabalha aqui há anos. / Ela tem trabalhado aqui há anos.

**Are you going to call him?**

Não é *will*. É BE + going to.

→ Você vai ligar para ele?

Treine esse segundo de pausa. Ele evita a tradução palavra por palavra.

## Resumo do capítulo

1. Etiqueta primeiro, tradução depois.  
2. **Do / does** = presente. **Did** = passado. **Will / won't** = futuro.  
3. **Can / should** não são “fazer”. São modal + base.  
4. **Are / was** = BE. Sem do.  
5. **Have** + coisa = ter. **Have** + particípio = perfect.

## O que vem no Capítulo 13

Os erros que o brasileiro produz **porque** a lógica do português vazou: *don't needed, did you went, do you are, can to, can works*. Cada um com o motivo, não só com o ❌.
